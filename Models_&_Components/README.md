| 1 | **TCS3200 Color Sensor Module:** What it is: A low-cost color sensor that converts light intensity into a square-wave frequency, easy to read with a microcontroller.
Main features:
8×8 photodiode array with red, green, blue, and clear filters.
Digital output (frequency ∝ light intensity).
Selectable color filter (R/G/B/Clear) and frequency scaling (100%, 20%, 2%).
Works with 3.3V or 5V systems, often includes white LEDs for illumination.
Strengths: Simple to use, flexible output scaling, decent sensitivity, and very affordable.
Limitations: Sensitive to ambient light and distance, requires calibration, filters have overlap (not perfect color accuracy), not suitable for professional-grade measurements.
Best uses: Color detection, object sorting, basic robotics, and simple DIY projects. | ![color sensor 356](https://github.com/user-attachments/assets/ce397574-aec2-4b49-a00d-8e3bb26f0e70) |
