Operating Range (distance): Best at 1–3 cm from the object (beyond that accuracy drops). Spectral Range: Sensitive to visible light, roughly 300–700 nm (R/G/B filters centered on respective wavelengths). Response Time: About 2 ms typical per color readout. Typical Output Frequency: Up to 500 kHz at full scale.
